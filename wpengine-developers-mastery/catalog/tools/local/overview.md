# Local — Overview

## Product intent

Local is a dedicated WordPress local development environment.

## Capabilities highlighted in WP Engine docs

- Rapid site creation with preconfigured stacks.
- PHP/server hot swapping.
- Isolated per-site configurations.
- Local Lightning performance architecture.
- MagicSync & Connect for hosting sync.
- Live Links for external sharing.
- Integrated WP-CLI and shell access.
- Extension ecosystem.
