# Headless Platform (Atlas) — Overview

## Scope

Headless Platform docs cover building and operating decoupled frontends backed by WordPress. [source:atlas-getting-started]

## Primary documentation buckets (subpage clusters)

- Getting Started
- Platform Guides
- Framework Guides
- API Reference

## Core jobs-to-be-done

- Create an app and deploy from Git provider.
- Connect a WordPress backend for content sourcing.
- Configure environments and custom domains.
- Inspect runtime logs and troubleshoot release issues.
- Integrate framework-specific stacks (e.g., Next.js + WPGraphQL/Faust patterns).

- For setup questions, load `getting-started-subpages.md`.
